# Support

EnvProof is an early-stage open-source utility. Report reproducible bugs and request features through the public repository’s Issues tab: https://github.com/muhammadsaeed-ai/envproof/issues. GitHub Discussions may be added if a dedicated community forum is enabled.

For a useful bug report, include the EnvProof version, Python version, operating system, exact command, expected versus actual behavior, and a minimal synthetic case. Please sanitize diagnostic data before sharing it publicly.
